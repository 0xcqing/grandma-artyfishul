The program sends exactly one word to `entry.txt`: **Artyfishul**, a grandmother's spelling of "artificial" typed the way the word sounds to her, aimed squarely at the thing everyone now just calls AI. It lands because it is a real family in-joke of a word: fond, a little wrong, and unmistakably hers, so the typo carries more grandma than any polished answer could.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
